# Kotton's Code Studio OS

Canonical Free Studio Edition: Canon → Realms → Content → Assets → Scenes → Shots → Production → Compositing → Audio → Master → QA/QC → Integrity → Approved → Distribution → Published → Live Verified.

## Stack
- Next.js + React + TypeScript
- Flutter client shell
- Firebase/Auth/Firestore integration boundary
- Cloudflare edge/DNS/Workers/R2 boundary
- GitHub + GitHub Actions CI/CD
- AppDeploy and B12 as studio/reference surfaces

## Governance
A status field is never evidence. State transitions require satisfied predicates, version, review, evidence references, and an audit record.

## Deployment state
This repository is the implementation source. Production deployment must be independently verified; no README status is a deployment certification.
