# Gate Predicates

## APPROVED
Requires integrity check, required QA records, Canon reference, age range, lesson definition, character validation, version, reviewer, and evidence references.

## PUBLISHED
Requires APPROVED + QA PASS + INTEGRITY PASS + MASTER READY + channel target.

## LIVE_VERIFIED
Requires PUBLISHED + correct visible version + metadata + thumbnail + parent guide + captions + links + audio verification.
