# KC Studio OS — Canonical Blueprint

## Control chain
CANON → REALMS → CONTENT → ASSETS → SCENES → SHOTS → PRODUCTION → COMPOSITING → AUDIO → MASTER → QA/QC → INTEGRITY → APPROVED → DISTRIBUTION → PUBLISHED → LIVE_VERIFIED

## Hard rules
- Downstream states cannot bypass upstream predicates.
- APPROVED ≠ PUBLISHED ≠ LIVE_VERIFIED.
- A status field is not evidence.
- Every gate is version-aware and auditable.

## Core entities
Canon, Realm, Content, Asset, Scene, Shot, ProductionJob, QARecord, GateRecord, DistributionRecord, LiveVerificationRecord.
